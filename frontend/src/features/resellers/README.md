# Resellers

**Owner:** Member 1 — Products & Inventory (Robin Louis Putong)

## Requirements (SRS v1.2)

- **FR-8 Reseller records.** Authorized users create, search, view and update internal reseller records, and see the sales linked to each reseller. Only Owner/Admin and Staff can access them.
- **NFR-5 (RA 10173):** contact details are personal data. Collect only what is needed and record consent.

## Scope notes

- These are internal records only. There is no reseller login, portal or invite e-mail.
- **Reseller transactions** are recorded as sales with channel `reseller` in the Sales module (decision D3). There are no separate order screens.
